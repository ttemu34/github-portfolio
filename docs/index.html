EcoWorkbench

Private

A desktop-style app that lets conservation teams design, run and review Ecoscope analysis workflows without touching a terminal.

  • Form-driven runs, saved EarthRanger, SMART and Earth Engine connections, run history and a built-in dashboard viewer
  • A visual workflow designer, DuckDB table previews, per-task logs and OpenTelemetry run traces
  • Credentials live in the OS keychain: never written to disk, never sent to the browser, scrubbed from logs
  • Double-click installers for Mac and Windows; backend tests and Playwright UI tests run in CI

Python · TypeScript · React · DuckDB · Playwright

JavaScript · deck.gl · webpack · GitHub Actions
